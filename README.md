# Suhaila Elbehairy

Personal research portfolio: computational biology, single-cell genomics and interpretable machine learning.

Live at **https://suhaila-samir-el-behairy.github.io**

## Editing

Everything is in `index.html`. Editable content is near the top of the `<script>` block:

- `TRAJECTORY` — the points on the trajectory tree. Notes beginning with `DRAFT:` are hidden on the live site; rewrite them in your own words and remove `DRAFT:` to show them.
- `PROJECTS` / `TOOLS` — the toolkit dot plot (0 none, 1 touched, 2 regular, 3 core).
- `LEARNING` — the "currently learning" pills.

To add a CV, upload `cv.pdf` to this repository and un-comment the CV link in the nav.
